    Scales

    Build a scale and read its structure.

    scale_from_leaftable 

    scale_from_leaftable(
    leaftable: Any,
    frames: str | Sequence[str],
    key: str | None = None,
    weights: str | Sequence[str] | None = None,
    default_weight: str | None = None,
    members: Mapping[str, Sequence[str]] | None = None,
    name: str = "",
    desc: str = "",
    attributes: Any = None,
    aliases: Any = None,
    **meta: Any,
) -> NestedScale

    Build a NestedScale from a flat table of atoms.

    leaftable has one row per atom, one column per name in frames (coarsest first) and optionally numeric weight columns. Blank strings in frame columns become null: that atom has no code at that frame.

    key defaults to "unit" when that column exists, else the finest frame. weights defaults to every numeric column that is neither a frame, the key, nor a reserved name. members defaults to first-appearance order. Extra keyword arguments are merged into meta (e.g. source, labels).

    scale_example 

    scale_example() -> NestedScale

    A small example scale with three awkward real-world features.

    • a code ("G1") reused at two frames, so lookups must name the frame;
    • a non-nesting pair -- group "GB" draws units from two classes;
    • a unit ("OTH") with no code at any coarser frame.

    scale_class

    NestedScale -- the dimension-agnostic core type (port of R/scale-class.R).

    A NestedScale is a nested partition of a set of atoms, in any dimension:

    • leaftable -- one row per atom: a column per frame, a unique key column (named by key) and zero or more numeric weight columns
    • frames -- frame names, COARSEST first
    • members -- frame -> the ordered code vocabulary at that frame
    • key -- name of the atom key column (default "unit")
    • meta -- name, desc, weights, default_weight, residuals, labels, source, and the sample bookkeeping (coverage, parent_totals, parent_name)

    Frames are partitions of the atoms, not necessarily a tree; conversion always routes through the atoms. Anything derivable is computed on demand.

    SCALE_ATTRIBUTE_KINDS module-attribute 

    SCALE_ATTRIBUTE_KINDS = ('property', 'factor')

    property = an invertible ratio (lhv, density); factor = one-way (an emission factor, a loss factor).
