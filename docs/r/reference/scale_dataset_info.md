# Describe a stored dataset without opening it fully

**\[experimental\]** This feature may change or be removed in a later
version.

## Usage

``` r
scale_dataset_info(path)
```

## Arguments

- path:

  A folder written by
  [`write_scale_dataset()`](https://optimal2050.github.io/nestedscales/r/reference/write_scale_dataset.md).

## Value

A list with `kind`, `axes`, `keys`, `files` and `bytes`.
