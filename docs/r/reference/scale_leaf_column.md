# The name of the leaf column

The column of the leaftable that identifies the leaves.

## Usage

``` r
scale_leaf_column(x)
```

## Arguments

- x:

  A
  [`NestedScale`](https://optimal2050.github.io/nestedscales/r/reference/NestedScale.md).

## Value

A single string.

## Examples

``` r
scale_leaf_column(scale_example())
#> [1] "item"
```
